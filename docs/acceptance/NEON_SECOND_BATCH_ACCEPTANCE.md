# Neon 第二批技术验证

2026-11-24。在 `codex/neon-first-batch` 工作树续做 [NEON-12～23](../product/NEON_ACCEPTANCE_CHECKLIST.md#第二批--竞技场辅助与真实模型)。本记录用于技术验证，产品验收由负责人确认。

## 实现范围

- 已提交的双边轮次同时进入气势条和图谱。气势为本地趋势参考。图谱能复用当轮已保存的真实分析，必须同时找到双方可定位的原句才标为 AI 来源。读取图谱没有额外模型调用。
- 当轮锦囊默认折叠。队友草稿和三段论填入可编辑文本区，预设辩词和本地框架走本地文本。语音识别结果只进草稿。音效可开关，AI 进度可展开查看浏览器测得的本次首字等待和吞吐。
- 四类个人模型配置由后端处理。密钥加密保存，设置页分别显示已保存、已校验和已实际调用。自定义地址须为服务端允许的公开 HTTPS 域名。连接测试是用户主动操作。
- 三档难度写入对局，生成目标按已确认的篇幅区间。已有真实回复的场次失去可用模型时提示重试，用户可另开本地练习局。练习标记随对局保存，供正式积分结算时排除。
- 个人模型用于真实批注、结构化复盘和重评。重评先认领版本，再在事务外生成反馈，完成后更新同一版本。保留原对局和既有重练。
