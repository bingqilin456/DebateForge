## 修改范围与约束

- `frontend/src/shared/limits.ts` 按含义集中认证长度、发言长度、辩题长度、总结/策略文本及条数限制、策略字节预算、历史分页与生成状态轮询。UI 提示、状态层及 API 使用同一含义的值；用户发言、AI 回复、辩题说明虽均为 2000，仍分别命名，总结与策略的 300 字及 3 条也分别保留。
- 普通请求 5 秒、生成请求 70 秒继续复用 client 的既有导出；状态只读轮询共用 2 秒间隔、120 秒预算，超时后仍须手动查询，不自动 POST。SSE 单帧 64 KiB、整流 2 MiB 各自命名，不与生成字符预算混用。
- 移除全局默认轮数。发送、流式、重试及总结调用均显式接收当前会话 `total_rounds`；DTO 校验仍要求已知赛制与总轮数一致、轮号有序、完成条数一致、请求标识/原文关联正确。非法总轮数及越界输入在请求前拒绝。
- `frontend/src/styles/theme.css` 收敛页面颜色、边框与圆角；复用锁定版本 Arco 的背景、边框、选中态、控件圆角变量。Arco 语义变量位于 `body`，共享别名同样在 `body` 解析。正式入口及独立认证预览都导入主题。
- 影响 App、认证表单、辩论/策略/总结面板、选题/历史视图及相关 API/状态测试。保留页面结构、交互和焦点样式，不新增依赖，不改锁文件、后端、迁移或部署配置。
