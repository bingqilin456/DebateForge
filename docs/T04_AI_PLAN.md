# T04 Eino 模型适配与预算 Implementation Plan

> 执行方式：Codex 负责设计、集成与验证；DSH 实现一个有边界的代码切片；新对话独立只读审查。仅本轮 T04，不提交 Git、不部署、不开放公网、不调用收费供应商。

**Goal:** 为 T05 提供可观察、可取消、受预算约束的完整响应生成接口。

**Architecture:** `internal/ai` 接收由受信任业务服务加载的单场辩题快照、立场、轮次与已完成历史；每次无状态构建消息。业务最小接口共用于真实 Eino Generate 适配与 Fake；供应商构造与业务入口分离，当前 main 不装配、不注册模型路由。

**Tech Stack:** 既有 Go 1.27.1；CloudWeGo Eino v0.7.13 与其官方 OpenAI 协议适配器 v0.1.13；不引入 Agent Runner、工具调用、流式响应或重试器。

**Spec:** 用户 2026-11-08 T04 授权、TASKS T04、PRD 输入输出约束、ARCHITECTURE AI 上下文与安全资源控制、API 错误契约。执行中负责人确认 DeepSeek `deepseek-flash`；真实调用仍以资源安全门槛为前提。

## Global Constraints

- 单次模型预算最多 45 秒；提供总请求 60 秒 Context 入口供 T05 从 HTTP 请求开始使用，尊重更短上游期限及取消。
- 每条 user 输入 1–2000 Unicode 码点且非全空白，AI 辩论回复最多 2000 码点；拒绝非法 UTF-8；不截断输入、历史或输出。
- 服务端确定角色与相反立场，历史仅接收连续已完成轮次对；调用者负责数据库所有权筛选，ai 无数据库访问权限。
- 窗口校验保留完整三轮和未来总结输入空间；供应商能力值必须显式配置。未核实能力不得声称真实兼容。
- 输出 Token 上限必须实际发到传输层；拒答、空白、超长、截断和工具输出受控失败。
- 用量缺失为未知，保留可信响应元数据；日志仅白名单字段，不写 Key、发言、完整 Prompt、原始错误。
- 不修改 T03、数据库、秘密文件、前端或无关依赖；不执行收费调用、commit/push/merge 或部署。
- T10 总结流程和 schema 解析本轮不实现；本轮为其预留足够窗口并记录限制。

## Review Focus

- 2000/2001 边界含四字节字符、空白与非法 UTF-8；拒绝发生在模型调用前。
- 伪造角色、乱序/缺轮/失败历史、跨请求共享切片不能污染消息。
- 超时、父取消、较短父期限直接取消 HTTP 传输，失败无额外请求。
- 429 限频与供应商额度不足分别处理；错误正文含秘密仍不得出现在受控错误或日志。
- usage 缺失、显式零、截断/拒答和未知 finish_reason 不得伪装为正常完整回复。
