# T04 一次性本地真实冒烟

仅供 `T04-20261108-local-once` 授权使用，不属于生产服务，无 HTTP 入口；不创建、修改、撤销 Key。复用现有 Eino `Generate`，不改变 `internal/ai`。

## 执行约束与顺序

1. 在 `backend/` 运行；默认启动不触网。只有 `--execute-once` 可执行，目录和授权 ID 固定，不提供重置、重试或路径覆盖选项。
2. 从 `DEEPSEEK_API_KEY` 或后端 `.env` 向程序内存注入现有测试 Key；不显示秘密，不记录请求头或原始错误。
3. `.cache/t04-smoke-20261108/launched.json` 用 `O_CREATE|O_EXCL` 抢占并 `File.Sync`。锁永久保留；包括预检失败在内的重入均停止，不自动删除半写入文件。
4. 只读 `GET https://api.deepseek.com/user/balance`，最多 5 秒，无重试/重定向；要求显式 `is_available=true`、CNY 余额可解析且覆盖 0.02048 元保守估算。该接口不提供自动充值状态，本次使用负责人声明的关闭状态。
5. Eino 使用固定匿名首轮输入和 `debate-v1`。实际序列化 HTTP body 必须与预定消息和参数一致，拒绝额外字段；发送前补成显式 `stream=false`、`tool_choice=none`，禁止思考、工具和搜索。完整 JSON 的 UTF-8 字节数加 1024 协议预留不超过 8192，输出 `max_tokens=512`。
6. 模型传输守卫 CAS 限次，先同步保存匿名 `wire-request.json`，再以 `O_EXCL` 创建并同步 `consumed.json`，然后才调用底层传输。消耗不回滚，失败、取消、拒答、超时和结果不明都不补发。
7. 模型 Context 最多 45 秒，整体 Context 最多 60 秒且尊重父取消。直连 TLS、无环境代理、无连接复用/HTTP2，移除可重放 `GetBody`，拒绝重定向；没有 SDK 自动重试、故障切换、工具执行或流式调用。
8. 同一整体 Context 内再只读查询一次余额，最多 5 秒，无重试；失败/取消记未知。保存白名单 `evidence.json` 后进程退出，锁及消耗标记保留，入口不可再次执行。
