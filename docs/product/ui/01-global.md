# 全局信息架构

对应 PRD §2、§10、§11；承载 P1–P11 的视图组织、跨页数据与响应式布局。本文不含页面细节，页面本身的线框与状态见各页面模块。

## 1. 适用规格

| PRD 章节 | AC-V2 | 实现状态 |
| --- | --- | --- |
| §2 训练模式与入口 | AC-V2-02、03 | 模式入口为目标态；单一赛制入口已实现 |
| §10 恢复、失败状态与历史 | AC-V2-23、25、30 | 恢复与历史已实现；V2 阶段态目标态 |
| §11 权限、隐私与安全边界 | AC-V2-04、23、34、36 | 所有权与 404 隔离已实现 |

## 2. 视图与路由

| 视图 | 目的 | 建议路由 | 相对现状 | 状态 |
| --- | --- | --- | --- | --- |
| 登录与恢复 | 登录、注册、刷新后恢复、失效重登 | 无独立路由，就地渲染 | 现有机制扩展 | `[已实现]` |
| 开始练习 | 选模式、定题、立场、强度、创建确认 | `#entry` | 现 `#topics` 扩展为“开始练习” | 自定义题 `[已实现]`，其余目标态 |
| 辩论工作台 | 阶段推进、发言、批注、争点卡 | `#debate=<id>` | 现有视图扩展 | 四轮练习 `[已实现]`，训练赛目标态 |
| 完赛复盘 | 复盘结果、四维、局部重练、PDF | `#review=<id>` | 新增 | 目标态 |
| 历史 | 列表、继续、复盘、重练入口 | `#history` | 现有视图扩展 | 列表与继续 `[已实现]` |
| 设置 | 模型服务（自带 Key）与额度状态 | `#settings` | 新增 | 目标态 |

- `[设计建议]` 路由名只是界面组织建议；真实路径与参数属接口与前端设计，不在本文定稿。现有实现用 hash 路由（`#topics`、`#debate=`、`#history`），扩展示例见演示图与各页面模块。
- `[已确认]` 工作台与复盘按会话 ID 直达，刷新后由服务端状态重建，不依赖本地暂存。
- `[设计建议]` 导航项在 V2 为“开始练习 / 历史 / 设置”三项；未登录时不显示需要会话的入口。

## 3. 跨页数据与事实源

| 数据 | 产生处 | 消费处 | 事实源 | 状态 |
| --- | --- | --- | --- | --- |
| 模式、立场、强度 | 开始练习（创建时） | 工作台、复盘、历史、PDF | 服务端创建结果，创建后不可改 | 立场 `[已实现]`；模式、强度目标态 |
| 辩题与背景快照 | 开始练习（创建时） | 工作台、历史、复盘、PDF | 会话内快照，创建后不可改 | `[已实现]` |
| 当前阶段、回合、发言方 | 服务端推进 | 工作台、历史 | 服务端权威阶段进度（[PRD §3.7](../PRD.md#37-目标状态模型待实施技术目标)） | 训练赛目标态 |
| 批注、异议、争点卡 | 分析结果与用户编辑 | 工作台、复盘、PDF | 服务端保存值；人工编辑优先（[PRD §6.6](../PRD.md#66-人工编辑与-ai-更新的优先级)） | 批注 `[已实现]`；异议、争点卡目标态 |
| 四维档级、复盘内容 | 复盘生成 | 复盘、PDF | 服务端保存的复盘结果 | 目标态 |
| 重练版本与反馈 | 局部重练 | 复盘页、历史入口 | 服务端保存；不改写比赛记录 | 目标态 |
| 模型服务配置 | 设置页提交 | 服务端调用链 | 服务端按用户隔离保管；浏览器只保留脱敏状态 | 目标态 |
| 额度与并发状态 | 服务端 | 设置页、工作台错误提示 | 服务端计数（展示口径见 [设置 §7](06-settings.md#7-待决与不做)） | 计数已实现；展示目标态 |

- `[已确认]` 四种辩手流派在 V2 暂缓。保留 V1 的选择、代码、历史字段与数据，见 [PRD §13](../PRD.md#13-暂缓项与后续需求池)。
- `[已确认]` 前端不得用本地缓存、SSE 片段或地址栏参数推导阶段与回合；这些只用于展示与恢复定位。
- `[设计建议]` 跨页只认服务端返回的会话 ID 与快照，页面之间不通过前端状态传递业务字段。

## 4. 桌面与移动组织

| 区域 | 桌面（建议 ≥1100 px） | 移动/窄屏（建议 <900 px） |
| --- | --- | --- |
| 导航 | 顶栏 + 主视图切换 | 顶栏 + 折叠菜单 |
| 工作台 | 双列：发言流主列 + 右栏（批注/争点卡） | 单列堆叠：主卡片含发言流和输入区，批注面板在下方；训练赛场中可另设争点区块，四轮练习赛后集中整理 |
| 批注 | 右栏列表，点击标记定位并展开 | 主卡片下方独立区块，点条目滚回原句 |
| 争点卡 | 右栏卡片列表 | 训练赛为独立区块；四轮练习不设场中入口 |
| 复盘 | 两列：四维与雷达 + 争点／建议 | 单列，雷达置顶＋维度卡片 |
| 输入区 | 主列底部固定 | 底部吸底，键盘弹起时保持可见 |

- `[设计建议]` 断点数值、栏宽与折叠方式均为设计建议，须在视觉设计阶段验证；当前实现用 1000 px 切换双列（见 [工作台](03-workspace.md#3-整体布局)）。
- `[已确认]` 无论桌面或移动，**语义不得只靠颜色**：批注类别同时给线型与文字标签（[PRD §5.3](../PRD.md#53-标记形式颜色--线型--文字标签q41)）。
- `[已确认]` 移动端批注为**主卡片下方的单列堆叠**，不做覆盖正文的抽屉（2026-11-19 负责人确认）；AC-V2-14 采用相同布局。批注与原文需同屏对照，抽屉会遮住原文。
