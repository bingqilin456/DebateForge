## Global Constraints

- 用户名 trim 后小写，3–32 ASCII 字母数字下划线；密码保持原文，12–128 Unicode 码点、最多 512 字节，拒绝无效 UTF-8。
- Argon2id 内存 19 MiB、迭代 2、并行度 1，独立随机盐及带参数编码，常量时间比较；不存在用户名也执行相同密码验证成本。
- Session 至少 32 随机字节，数据库仅 SHA-256 原始摘要 BINARY(32)，独立随机 CSRF；固定 24 小时，退出只撤销当前 Session。
- 所有业务 POST 精确匹配配置的完整 Origin；需认证 POST 另校验 X-CSRF-Token。匿名注册/登录忽略旧 Cookie。
- Cookie HttpOnly、SameSite=Lax、Path=/、无 Domain。开发使用 siyige_session_dev；HTTPS 安全策略使用 __Host-siyige_session 和 Secure，不能复用开发名称。当前 APP_ENV 仍只允许 dev/test，不新增生产部署入口。
- 请求体最多 32 KiB；JSON 输入单文档，非法输入 400；过大 413。业务成功/失败均 no-store，request_id 信封与响应头一致；204 无正文。
- 注册同 IP 每小时 5 次；登录 IP 与规范化用户名每分钟各 10 次；密码计算前限流，429 带 Retry-After。不信任外部转发头。
- 数据库操作从请求 Context 派生，最多 3 秒；错误不泄露 SQL、凭据、内部 cause。唯一索引处理并发注册冲突。
- 不改已执行迁移，不自动迁移/播种，不操作开发库、不重建容器/卷、不提交推送部署。

## Review Focus

- 不存在用户与错误密码同为 401 invalid_credentials，执行同参数 Argon2id；损坏编码不能触发任意资源分配或泄密。
- 分块/未知 Content-Length、尾随 JSON、非法 UTF-8 和 32 KiB 边界均经过真实输入处理。
- 固定过期时刻、伪造 token、重复 Cookie、旧 Session 撤销与并发注册不得旁路校验。
- 限流并发安全，窗口确定性测试；计数存储有界，攻击者不能用用户名/IP 无限制占内存；认证哈希并发有界。
- 数据库不可用/写入失败不发有效 Cookie；日志和 JSON 不含密码、Session 原值、CSRF、SQL/DSN；现有数据保留。
