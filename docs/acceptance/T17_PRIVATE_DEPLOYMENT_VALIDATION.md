| 范围 | 私有目标实测 |

| 认证与最小权限 | 正常注册和登录，4 个合成账号的存储均为 Argon2id 哈希。错误密码 401，退出后原 Session 401。检查 Secure、HttpOnly 和 SameSite Cookie 属性。未登录访问为 401，缺失 CSRF 或错误 Origin 返回 403。 |
| 选题及赛制 | 已登录可读至少 5 道辩题。浏览器从辩题页选择反方并创建会话；接口核对正方也可创建。客户端传入 `quick_3` 无法覆盖新会话的 `standard_4`，总轮数为 4。 |

| 断线与幂等 | 在 SSE `start` 后主动断开，按原 `turn_id` 和 `client_request_id` 查询到已完成的正式轮次，仅有 2 条消息，未重新提交。分钟配额饱和时同键重放被拒 429。自然窗口结束后同键重放只返回 `start`、`done`，轮数和正式消息均未增加。 |
| 历史、总结与用户隔离 | 历史分页无重叠，策略生成和读回成功，未完成会话生成总结返回 409。四轮完成后总结返回 `completed`（Schema 1）。跨账号访问他人详情及写总结均返回 404。 |
| Nginx 与安全边界 | 超长请求由 Nginx 返回 413，响应头和 JSON 请求 ID 一致，超长测试正文未回显。不存在的 API 返回 404，未落入前端 HTML。 |
| 重启和持久化 | 应用恢复到标准 Fake 配置后，重新登录读回同一历史。再独立停止及启动 MySQL，停机时 live 200、ready 503，恢复后 ready 200。同一数据卷创建时间、四轮八条消息和总结保持一致。 |

## 受控公网真实首轮

2026-11-23 01:00（北京时间），由已核验的同一工作站经公网 HTTPS 发出一个合成首轮，使用 DeepSeek Flash。费用专项独立复审 **PASS**，范围仅为此次来源、会话和费用窗口。

| 项目 | 现场证据 |
| --- | --- |
| 费用和网络准入 | 只读余额核对确认 CNY 余额覆盖单次预留。沿用 T16 同一个持久账本和窗口，隔离成功记录与完成标记同卷同 inode，首轮前无公网预留。公网候选应用无默认路由和公开端口，专用转发器只允许指定供应商 TLS 入口，验证官方主机证书，拒绝其他 SNI。占位干跑零模型请求。 |
| 现场控制 | 固定公网来源和合成会话。在实际公网 HTTPS 上验证工作站收到就绪和账号身份响应，收件端落盘后才送心跳。候选获得启动后的新鲜心跳才允许首轮。单次预留 ¥0.040960，输入上限 16,384 Token、输出上限 1,024 Token，无补发。 |
| 响应和读回 | 公网首轮返回 HTTP 201。同一账号经 HTTPS 读回同一请求的 1 个完成轮次和 2 条持久化消息。账本显示仅 1 次公网预留并成功。 |
| 用量和费用 | 供应商返回输入 356、输出 472，合计 828 Token。按未命中缓存价格保守估算 ¥0.004488，供应商实际扣款尚未核对。 |
| 恢复 | 已落盘停用标记，公网 upstream 切回标准 Fake，终止真实候选应用与专用转发器，移除临时密钥。工作站从原公网 HTTPS 再次验证 ready 200。 |

该结果验证 [T07-COST-01](../planning/TASKS.md#t07-cost-01-供应商硬预算缺失) 的单次受控公网执行。持续真实模型运营和扩大来源范围仍待生产准入与负责人验收。
