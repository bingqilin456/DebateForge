# Neon 第一批技术验证

2026-11-24。基线为 `6917bdf`，实现位于本地 `codex/neon-first-batch` 工作树。范围是 [NEON-01～11 和已确认的 D1–D7](../product/NEON_ACCEPTANCE_CHECKLIST.md)。本记录用于技术验证，清单的产品验收仍由负责人确认。

## 实现范围

- 桌面五入口与窄屏菜单、独立示例复盘、四轮开赛、计时与滚动。新建走 `standard_4`，历史 `quick_3` 与 `training_v2` 按原赛制恢复。
- 标准四轮沿用现有 `/turns` 流式、幂等和恢复流程。相同的前缀清理用于流式片段和正式回复，保留作为正文的括注。
- 双边批注经 API 校验后按原文坐标定位。标准四轮和训练赛共用 `00019` 重练版本，原句与改写均可回看。重练走同一 Gate 的训练请求计数，正常四轮、总结、复盘后可继续重评。
- 复盘示例使用固定五维样本。真实模型批注、正式五维评分、裁判、积分与社区仍按后续批次实施。
