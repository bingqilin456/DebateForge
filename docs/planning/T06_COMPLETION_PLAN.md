## 容易遗漏的验证

1. 登录成功与 pending 收尾的竞态不能漏读辩题。
2. 响应丢失和 202 只能触发详情查询，不自动再生成；同键显式重发保持原文。
3. 查询失败/404 不能恢复发送能力；已失败轮保留原文，不冒充 T09 重试。
4. 退出失败不能伪装登出；保护接口 401、切换用户和卸载后不能回显旧数据。
5. 2000/2001 Unicode 码点、HTML 样式输入、刷新恢复、有限轮询和移动端不能破坏正常首轮。
