## 独立审查及定向修复

初审确认 4 项 P2：非 assistant 角色被接受；部分失败响应丢失已返回 usage；非法 UTF-8 被 SDK 替换后接受；非标准错误体导致 HTTP 状态误分类。新增 `review_regression_test.go` 后先执行 `go test ./internal/ai -run TestReview -count=1`，四组真实失败；修正后 `go test ./internal/ai -count=1` 通过（0.519s）。

修复通过 SDK 解码前的逐请求 Transport 观察完成，原始响应最多读取 1 MiB 并关闭；严格要求 wire role 为 assistant，UTF-8 必须有效，HTTP 状态不依赖 JSON 错误体，空 choices/缺少 index=0 仍保留已知用量。同步收紧“Known 且值不等于”这种允许未知通过的弱断言，取消空 choices 丢弃用量的旧 characterization。内容过滤 Refused 标志亦先测试失败后修正。

复验又发现 1 项 P2：收到 200 头后，较短 HTTPClient.Timeout 在读 Body 时触发，已识别的 model_timeout 被格式分支覆盖。新增 `TestReviewBodyReadTimeoutStaysTimeout` 用 25ms 客户端期限等待真实请求 Context 取消，先观测 model_error 失败，再修正为超时/取消分类优先。`go test ./internal/ai -run TestReview -count=1` 通过（0.490s）。最终 `go test -race ./... -count=1` 全部包通过（ai 2.568s），`go vet ./...`、`go build ./...` 退出 0，`go mod verify` 通过，gofmt/差异检查通过。

**独立最终复验：通过，当前冻结源码无阻塞发现，累计 5 项 P2 均关闭。** 审查对话独立执行 AI 包全量 race（2.856s）及临时 overlay 超时补测（race 下退出 0），确认 deadline cause 保留、原 Body 关闭、请求一次、调用方 Transport 未被修改，并已覆盖观察层并发隔离/父取消/1 MiB 边界；冻结前后源码哈希一致，HEAD 为 `bbe7df2`。审查未修改仓库、读取秘密或调用真实模型。该结论不覆盖真实模型冒烟、供应商硬预算、端到端 HTTP 总预算或人工验收。
