## 入口取舍与行为

PRD 核心流程、AC02 和 Phase 2 独立选题页要求均支持 TopicsView 统一创建，没有必须保留两份表单的明确需求。本次没有需求冲突。

- TopicsView 是唯一选题、立场、流派及创建表单。初始不选辩题，保留正方和 logical 默认值。主视图只读服务器会话、对辩和恢复；开始新的练习进入选题流程，仍可返回原会话。
- 删除 FirstTurnPanel 的默认选题和创建表单、firstTurn 状态的 start 创建分支，保留现有 API。输入、CSRF、权限、standard_4、轮次认领和模型规则均未修改，没有新增依赖。
- 同步防双击，创建时锁定表单、相关导航及退出按钮。成功只发一次 created，顶层打开一次详情 GET，以服务器保存结果展示，不拼装空会话详情。
- 网络失败、总超时、损坏响应、5xx、HTTP 408 及其他未知状态均锁定创建并先查历史，不自动重发，也不提示另建。结果不明面板在视图切换时保留，避免切页绕过提交锁。
- 明确拒绝的 400/401/403/404/429 沿用受控错误处理；可恢复输入失败保留选择供修正，401 由共享认证状态清理。刷新及退出重登保留会话地址，重新请求服务器详情；历史页继续复用同一详情入口。
