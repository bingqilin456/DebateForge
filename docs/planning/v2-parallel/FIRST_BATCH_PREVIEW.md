# 产品 V2 第一批：四轮赛后联合预览

> 状态：负责人已在会话确认本地联合预览，并授权提交和推送本分支。确认仅覆盖下述本地体验，不代表正式上线、迁移验收或第二批开始。

## 怎么体验

在 `frontend/` 运行 `npm ci`（首次）及 `npx vite --config e2e/issue-card.vite.config.ts`，通过本机浏览器打开 `http://127.0.0.1:5273/first-batch-preview.html`。

1. 从争点卡点引用，跳到对应轮次并高亮原句。不能唯一核对时只显示“原文待核对”。争点卡可改名、合并或移除。
2. 在自己发言里选一句，再点「选句重练」；也可以直接「重练整条」。不提交改写就不会生成反馈。提交后的版本独立保留，不改正式发言。
3. 点「生成复盘」，看主要争点、优点、优先改进与四维雷达。「观察不足」留空，不当作 0 档。可以从有原文依据的维度跳回原句、带着建议去重练。
4. 两个“演示失败”开关分别用于复盘和重练。重练失败会保留改写并重试同一版本；复盘失败不影响原文、争点卡和已有练习。同一标签页刷新可回看已保存的演示结果。

## 范围与后续门槛

- 争点卡沿用已签收的锚点；联合预览使用同一场四轮示例，预览端口不会代理业务请求。
- 重练切片独立验证本场、本人、完赛、已提交原文及版本重试。演示页面与后端单测各自使用替身，并非浏览器到真实数据库的联调。
- 正式持久化、隔离库迁移实跑、真实模型质量和费用验证均未获本次预览证明。第二批训练赛接入还依赖 V2-01/02 的权威完赛状态、正式发言快照与阶段事件，保留原有依赖。PDF、设置不在本批范围。
