# 03 局部重练

范围为 V2-08，对应 [PRD §5.7](../../product/PRD.md#57-局部重练q16q28q32q39)、[完赛复盘](../../product/ui/04-review.md)及 AC-V2-17、26。

## 设计与边界

- 首条可独立实现的路径是完赛后选中本人已保存发言的一段原文，可选填本次改进目标。服务端按会话所有权、完赛状态、发言方和原文匹配验证；未完赛、AI 发言和其他会话原文拒绝进入。
- 面板先展示原句、已有批注（存在时）与练习提示。打开面板不触发生成。用户提交 1–2000 字改写后生成对照反馈，说明原问题是否改善、理由和可能的新问题。给局部提示，保留用户自己的写法。
- 每次重练保存独立版本，绑定同一原文，可回看改写、反馈与失败状态。失败后按已知版本显式恢复，避免网络重发造成重复版本或调用。重练表与正式比赛发言、后续步骤隔离。
- 先用四轮完赛和无批注夹具交付。后续复用标注入口，仅在引用指向本人发言时提供快捷跳转。批注缺失、定位失败或复盘失败时，仍可从已保存的本人发言主动选段。
- 记录模型和重试策略按 TE-01、TE-10、TE-12 评估，额度从服务端读取。失败时保留本次输入和其他版本。

## 执行与验收

1. 定义选段与重练版本的动作表，并用固定夹具验证是否完赛、是否本人、是否本场原文。
2. 用 Fake 验证用户提交后才生成，输入空白、边界字数、重复提交、生成失败及恢复、多版本刷新不丢失。对比原会话发言、阶段及复盘结果，用例中确认它们未被改写。
3. 用 Mock 在完赛页验证无批注仍可重练、有批注时能带入同一原句、失败保留改写。完赛页公共入口与 04 由整合负责人一次接线。
