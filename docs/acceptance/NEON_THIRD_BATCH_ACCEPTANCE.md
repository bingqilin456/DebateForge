# Neon 第三批技术验证

2026-11-24。在既有工作树续做 [NEON-24～31 与 NEON-46](../product/NEON_ACCEPTANCE_CHECKLIST.md#第三批--裁决elo-与思弈杯)。技术验证完成后由负责人确认产品验收。

## 实现和规则

- 三位官方裁判与自定义裁判可累积选择。用户可单独保存多份裁判模型配置，席位只展示本人保存的别名和演示选项。自定义裁判默认私密，公开共享风格，不共享模型或密钥，撤回后不能用于新裁决。
- 裁决保存每席结果。三席中一席失败可先用有效真实席位出分或单独重试；演示票不会参与真正结算。五维聚合、胜负和正式积分在报告中展示。已结算场次的原结果固定，重评参考分保存在改写版本里。
- 沿用样板的 1420 初始积分、1400／1500／1600 匹配分界、四阶胜出加分 15／20／25／32、负场扣 8 和 1000 下限。新账号仅解锁初赛。未解锁的赛段可开练习局；只有当前最高解锁赛段胜出才晋级。普通正式四轮训练胜出加 18，平局按已确认规则记 0。
