# 04 赛后复盘与四维训练参考

范围为 V2-13、V2-10、V2-11，对应 [PRD §8](../../product/PRD.md#8-赛后复盘与四维训练参考)、[完赛复盘](../../product/ui/04-review.md)及 AC-V2-21、22、24、26；失败保留沿用 PRD §10.3。PDF 后续由 V2-14 消费已保存的结果。

## 设计与边界

- 正式会话完赛后即可读原文与已保存分析。复盘单独保存和恢复，有未开始、生成中、成功、失败状态。首版设计以用户显式请求为例，自动发起策略保持待决。重试只补失败部分并保留成功结果、已有批注与人工编辑。
- 复盘显示主要争点、论证优点和少量优先改进建议，各条尽量带同场原文引用。先用四轮夹具和已保存结果独立实现页面，争点卡或重练模块接入后再替换相应入口。
- 四维为论证结构、回应针对性、证据使用、概念与范围。每维有行为依据、具体验证原文和改进提示，档级为 1–4 或观察不足。缺引用或观察机会不足时标观察不足，不计为 0 或 1 档。四维标准对三档训练强度相同。
- 先定 V2 四维数据形状，再做雷达。缺项保留空缺或显示文字卡片，移动端保留可读维度与图表入口，点击可查原文、批注或重练。兼容旧总结读取，0–100 的旧格式按原语义处理。PDF 只读复盘及原文快照。
- 对 Q49 准备人工标注样例与判定表，记录一致与分歧。Fake 能验证数据结构与恢复，真实样例的质量结论需单独授权和记录。旧总结兼容和结果落库按 TE-08 评估。

## 执行与验收

1. 先用 Fake 锁定“完赛但复盘失败”的独立状态。验证刷新、只补失败、重复点击、已成功内容和人工编辑原样可读。
2. 做四维入参和结果校验，覆盖四维齐全、部分观察不足、全部观察不足、引用越权或失效、旧总结可读。再实现雷达联动、文本回退与窄屏。
3. 模拟 03 尚未接入及 02 定位降级的状态，确保原文与建议仍可读。01 阶段契约稳定后，再验训练赛完赛、恢复与复盘入口。
