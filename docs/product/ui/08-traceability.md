## 3. 未决项

| 事项 | 归属 | 为什么不能现在定 |
| --- | --- | --- |
| 多配置/切换时机、默认配置 | 产品 | 用户只说“自带 Key”，未说是否多套 |
| 额度与用量展示口径 | 产品＋技术 | 需先定展示的是应用计数还是供应商概念，且不虚构余额 |
| 复盘未开始时的自动生成策略 | 产品 | PRD 只定“独立生成、可重试”，未定是否自动一次 |
| 争点卡移除后能否恢复、合并/移除是否可撤销、改名是否保留内部原名记录 | 产品 | PRD 未确认撤销/恢复/审计 |
| 测试连接针对「已保存配置」还是「当前完整候选配置」 | 产品＋技术 | 保存/测试对象一致性未定；测试协议属 TE-18 |
| 赛后批注类型筛选 | 产品 | 确认记录列为建议、未单独确认 |
| 受控试用期间是否隐藏手动补做按钮 | 产品＋技术 | 改造方案提议增加 `manual_retry_enabled` 可选字段，未定 |
| 复盘失败时是否导出精简 PDF | 产品 | Q47 未覆盖失败态导出；属新增功能 |
| 旧 V1 历史的阶段映射与 V2 能力开放 | 技术 | TE-13 待评估 |
| Key 加密、轮换、删除 | 技术 | TE-14，未评估 |
| 地址校验与 SSRF（含重定向/内网） | 技术 | TE-15，未评估 |
| 供应商协议与模型适配 | 技术 | TE-16，未评估 |
| 按用户配置路由与在途替换 | 技术 | TE-17，未评估 |

## 4. 未执行项

本文**未**执行：页面代码、视觉资产、真实组件截图、高保真原型、产品代码的浏览器验证、组件实现、接口设计、加密方案、迁移、真实模型调用、费用实测、数据库操作与部署。

本轮实际执行的唯一验证是：演示图由静态 HTML 用本机 Edge 无头模式渲染成功，并逐屏目视核对布局。该检查只证明线框可渲染，不构成任何页面行为的验收。

## 5. 维护方式

- PRD 行为变化时先改 PRD，再同步对应模块；本文不得反向覆盖 PRD。
- 新增 `[设计建议]` 时保留标记；负责人确认后改为 `[已确认]` 并注明来源，同时检查是否需要在 PRD 补 AC。
- 模块间只通过相对链接引用，不复制结论；同一事实只在 PRD 定义一次。
- 演示图更新后同步替换 `mockup/shots/` 下同名文件，并核对模块里的文字线框仍与图一致。
- 本文与 [V2 页面设计补充验收记录](../../acceptance/PRD_V2_UI_SUPPLEMENT_ACCEPTANCE.md) 配套；验收记录只登记已执行检查，不代替负责人签收。
